# For‑Loop Counter (1 to 5)
This program uses a for‑loop to count from 1 to 5. The loop increases automatically without needing manual increments.

## Features
- Uses a for loop
- Counts from 1 to 5
- Prints each number

No += needed because the loop updates itself


## Learning Purpose
A small exercise to practice:
- for‑loops
- the range() function
- automatic loop iteration






# While‑Loop Counter (1 to 3)
This program uses a while‑loop to count from 1 to 3. The counter must be increased manually inside the loop.

## Features
- Starts counting at 1
- Uses a while loop with a condition
- Requires += 1 to update the counter
- Prints each number


## Learning Purpose
A small exercise to practice:
- while‑loops
- manual counter updates
- loop conditions
